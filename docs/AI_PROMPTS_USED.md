## What would have made the prompts better
- **Share the complete brief in the first prompt.** The first ten prompts worked from a shortened description, so password reset, the book description field, history and the document deliverables were only found at step 10.
- **State non-functional expectations early** (security, concurrency, tests) instead of asking for them step by step.
- **Ask for a review earlier.** The review (prompt 9) found problems that the first 59 tests missed; running it after each feature would have caught them sooner.
